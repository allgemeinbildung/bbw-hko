# Auftragsliste

Eine Zeile pro Einheit. Die Cloud-Session arbeitet sie von oben nach unten ab.
Jede Zeile braucht einen freigegebenen Bauplan unter
`docs/cloud-run/bauplaene/<ordnername>.md` (Vorlage: `_VORLAGE.md`).
Vorschlag für die Auswahl: `docs/cloud-run/abdeckung.md` (`npm run abdeckung`).
Nicht aufnehmen: Lebensbezüge mit ⚠ (kein Kernkapitel), T7, EBA.
