`detail` nennt zwei Tätigkeiten — Grafiken interpretieren und die Absicht von
Texten erkennen —; sie sind auf die Hefte verteilt: **Heft A liest eine
Grafik, Heft B einen Artikel** (A und B verschieden im Typ). Jede Karte trägt
`sprachmodus` «Rezeption schriftlich und bildlich». Die Absicht eines Textes
übt Heft A an der Herkunft der Zahlen (Branchenverband), Heft B an der
Vertiefung 1 (Versicherer).
